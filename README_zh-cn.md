# Choysum

[English](README.md) | 简体中文

🌱 **Choysum：专为二次开发打造的 TypeScript 运行时，内置开箱即用的 ERP 核心模块。**

*   **⚡ TypeScript 全栈开发**：前后端统一使用 TypeScript 进行开发。开发者只需掌握 **TS/Vue** 即可完成从业务建模到页面渲染的全栈流程，极大降低团队上手门槛与协作成本。
*   **🧩 二次开发自由**：通过编译期迭代模型机制，允许自由覆写和扩展原生功能，实现核心代码与定制业务的完美隔离。
*   **🚀 纯 Go 驱动极速底座**：零二进制依赖，单文件即可部署，开箱即用。业务层不依赖 Node.js 环境，由内置高效引擎直接驱动，享受 Go 高并发调度与极致性能。

---

## ✨ 核心特性

### 1. 基于 TypeScript 的全栈开发体验
业务模块（包括后端数据模型、服务接口和前端 **Vue** 视图）统一使用强类型 **TypeScript** 编写。开发者只需掌握 **TS/Vue** 即可完成从业务建模到页面渲染的全栈开发。**前后端类型同构**不仅极大降低了团队上手门槛，还能在编译期提前拦截掉绝大多数常见的类型错误。

### 2. 编译期迭代模型扩展架构
针对复杂的二次开发需求，Choysum 汲取了迭代式模型扩展思想（受 **Odoo** 启发）。为了消除动态语言“运行时魔法”带来的性能损耗，我们将**模型与页面的合并与替换全部迁移至编译期**。这不仅实现了完美的模块化设计，使核心代码保持纯净，更实现了零运行时开销，大幅提升了系统的可维护性与平滑升级效率。

### 3. 原生 gRPC 协议支持
系统的网络层基于 gRPC-Native 理念构建。后端的 TypeScript 领域服务会被自动映射为标准的 gRPC 接口，前端通过框架自带的 grpc-web 协议实现与后端的同构交互。这免去了手动编写路由与序列化接口的样板代码；同时，系统自动输出的标准化 .proto 契约，能让你以极简方式生成跨语言 SDK，无缝接入现有的微服务网络。

### 4. 高性能 Go 核心底座
核心引擎由 **Go 语言** 构建，内嵌 TypeScript 编译与执行引擎。业务层的 TypeScript 代码**完全不依赖外部 Node.js 环境**，直接在 Go 创建的独立运行时实例中高效执行。这不仅利用了 Go 的高并发调度保障系统稳定性，部署时也只需一个已编译好的 Go 可执行文件，彻底摆脱了复杂的运行环境依赖。

### 5. 多数据库方言适配
框架在底层 ORM 层面提供了高度的抽象与统一的方言兼容层。目前原生支持 **PostgreSQL、MySQL 和 SQLite** 三大主流关系型数据库（更多数据库支持计划中）。高度的底层适配让开发者无需关心特定数据库的语法差异，可根据业务体量与部署场景，极其灵活地选择或迁移底层存储。
